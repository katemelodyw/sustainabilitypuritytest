📊 GLT Database Integration

Connect this quiz to a Google Sheet so every student submission, carbon score, and responses are logged automatically.

📖 Updated Apps Script Setup Code
  1. Create a new Google Sheet named "GLT Survey Data".
  2. Column headers (Row 1): Timestamp, Score, Archetype, CarbonMonth_kg, CarbonDay_kg, Q1 to Q15.
  3. Go to Extensions > Apps Script and paste: 
    function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  var row = [new Date(), data.score, data.archetype, data.carbon_month, data.carbon_day];
  for(var i=1; i<=15; i++) { row.push(data["q"+i] || ""); }
  sheet.appendRow(row);
  return ContentService.createTextOutput("Success");
}
  4. Deploy as Web app, setting access to Anyone.
